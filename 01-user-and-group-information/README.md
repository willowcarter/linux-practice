#Display User and Group Information

##Objective
Practice using Linux commands to identify the current user and view group information.

##Commands Used
- whoami — displays the current username.
- id — displays the user's UID, GID, and group memberships.

##Results
Current user: labex
UID: 5000
Primary GID: 5000
Groups: labex, sudo, ssl-cert, public

##What I Learned
Linux uses UIDs and GIDs to identify users and groups. Users can belong to multiple groups, which can affect their permissions and access to system resources.

##Security Relevance
User and group information is important when troubleshooting permissions and understanding what access an account has on a Linux system.
